# Лабораторна робота №10. HTTP-запити та відповіді

- **API-клієнт:** curl 8.18.0 (командний рядок). Колекцію також підготовлено у форматі експорту Insomnia (v4).
- **Базовий сервер:** https://httpbin.org (резервний httpbingo не знадобився).
- **Навчальна позиція меню:** «Деруни з грибами», категорія `main`, ціна 145.

## Файли

| Файл | Призначення |
| --- | --- |
| `requests.sh` | 12 запитів колекції; `bash requests.sh` виконує їх і зберігає відповіді в `responses/` |
| `responses/` | Фактичні відповіді сервера (статус, заголовки, тіло); IP-адресу в полі `origin` приховано |
| `Insomnia-lab10.json` | Та сама колекція для імпорту в Insomnia |

## Імпорт в Insomnia

Insomnia → **Import** → **From File** → виберіть `Insomnia-lab10.json`. Буде створено колекцію
«Лабораторна 10 — HTTP» з 12 запитами; базову адресу задано змінною середовища `base`.
